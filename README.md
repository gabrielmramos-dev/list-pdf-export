# Site — List PDF Export for ClickUp

Static site (no build step). Pages: `index.html`, `how-to-export-clickup-list-to-pdf.html`, `privacy.html`.

## Publish free on GitHub Pages
1. Create a **public** repo named `list-pdf-export` (GitHub Pages is free on public repos).
2. Upload everything in this folder to the repo root (keep the `assets/` folder).
3. Repo → Settings → Pages → Source: "Deploy from a branch" → Branch `main` / `/ (root)` → Save.
4. Wait 1–2 min. URL: `https://<your-username>.github.io/list-pdf-export/`

Optional later: buy a domain and set it under Settings → Pages → Custom domain.
