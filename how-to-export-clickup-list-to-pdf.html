How to export a ClickUp List to PDF

Updated October 2026 · 5 min read

There's no single "Export List to PDF" button in ClickUp, but there are four practical ways to get a PDF of a List. They give very different results, so here's what each one is good for.

Disclosure: I built option 4, a Chrome extension. Options 1 to 3 are ClickUp's built-in features and work without installing anything.

1. Print the List view (Ctrl/Cmd + P)

ClickUp's help center documents printing views directly from the browser:

  1. Open the List view and apply the filters and columns you want.
  2. Scroll to the bottom so every task loads (ClickUp loads long Lists as you scroll).
  3. Press Ctrl+P (Windows) or Cmd+P (Mac), choose Save as PDF.
  4. If tags or colors are missing, enable Background graphics under "More settings".

Good for: a quick printout for yourself.

Keep in mind: you get the app's screen as it is, so layout depends on your window, open sidebars and which subtasks are expanded.

2. Export to CSV or Excel, then save as PDF

  1. In the List or Table view, open the view settings and choose Export view.
  2. Pick visible columns (or all columns) and download CSV or Excel.
  3. Open the file in Excel or Google Sheets, format it, then File → Download/Save as → PDF.

Good for: data you'll keep working on in a spreadsheet.

Keep in mind: you'll spend time on formatting (column widths, wrapping, grouping, page breaks) before it looks presentable.

3. Dashboard PDF

Dashboards can be downloaded as a PDF from the Dashboard menu. You can add a task list card that shows tasks from your List.

Good for: charts and an executive overview.

Keep in mind: users report that task list cards in Dashboard PDFs only show a limited number of tasks (around 30), so it isn't meant for long Lists.

4. A Chrome extension that builds the PDF for you

List PDF Export for ClickUp reads your List through ClickUp's official API and builds a print-ready document:

  • The whole List in one report, no scrolling first
  • Subtasks indented under their parent, in your view's order
  • Custom fields as columns; you pick which columns to include
  • Grouped by status, optional page break per status, Letter or A4
  • Your logo and report title (Pro)

Good for: status reports you send to clients or management.

Keep in mind: it needs a one-time ClickUp personal API token, and it's a Chrome (Chromium) extension.
